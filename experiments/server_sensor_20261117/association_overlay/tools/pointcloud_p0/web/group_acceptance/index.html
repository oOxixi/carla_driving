2. 五个指标和统计口径

指标原 55 次首批新 20 组解释

点级 Precision 只统计能够核对目标真值的已分配点；未匹配的点另列。点级 Recall 的分母是“有匹配检测框内、经语义 LiDAR 核对属于目标车”的点，没有检测出车辆的情况不在该分母内。定位覆盖率以预期车辆为分母，因此包含漏检。

4. 重叠和压力测试如何理解

新增 54 个实际采集画面包含首批 20 组和补充的 34 组；其中 33 组有两个物理车辆的真值框投影重叠，20 组里两辆车都被 YOLO 匹配到，19 组的两个 YOLO 框实际重叠。只对可评分的框对统计误合并。

首批 20 组中的 5 组是在真实 YOLO 检测框上人为注入不同类别的重复框，用来模拟类别混淆；不是 YOLO 自然产生了 5 次重复检测。

压力测试还人为将两辆真实车的检测框扩大到几乎相同，模拟严重重叠；不同于自然 YOLO 输出。深度规则针对前 16 组中的失误进行了调整，另有 8 组后采集的数据单独验证；仍不能推断所有遮挡场景都安全。
