# 0.20 低置信度候选独立核验：完整实验报告

## 实验条件

原始 21 帧、35 个指定目标；模型 SHA-256 `c3517177a74c47589e29cffe92883b8310046434fc1f886ee00ee3f6fa782b0f`，输入 640×640，原类内 NMS IoU 0.45。正式阈值 0.35，辅助候选 0.20≤分数<0.35；一对一目标匹配仍为投影框 IoU≥0.30。21 帧正式检测输出与先前基线重放一致。

正式通道先运行原方案 C（包含原有雷达输入），冻结正式结果；保留投影到正式框内的全部 LiDAR 点及所有正式选中点。辅助通道仅对剩余点运行原方案 C，使用空雷达，不将辅助结果输入控制。辅助地面在余下点上重新拟合，可能与正式通道地面模型不同。

语义 LiDAR 及目标包围盒只用于结果核对：普通 LiDAR 点以 0.08 m 最近邻近似对齐语义点，无法匹配的点记未知；目标角色来自原自动匹配，而非独立身份真值。雷达为候选框独占且未落正式框内的回波，并用目标包围盒扩展 0.2m 做近似核对；有回波不代表独立身份已验证或达到实时同步要求。

## 结论与边界

1. 9 个新增候选经人工确认均有车辆，当前样本内未标出背景误检；两框覆盖多车，必须保留身份歧义。
2. 8 个候选去地面后至少 3 个点但没有可接受点簇，1 个不足 3 点。例如 extra_250_25 有 16 个目标点，当前半径 0.4091m 下均为单点；离线计算 3 个目标点连通至少约 0.4483m，不能因此宣布可信定位。
3. 人工判定多车的两个候选在算法输出中是 VISUAL_ONLY，而非 AMBIGUOUS；这是本实验尚未解决的设计缺口。人工标注不进入模型，不能声称算法已经识别了这两处风险。
4. 四个算法标记 AMBIGUOUS、五个 VISUAL_ONLY；没有候选进入 FOLLOW，也没有完成独立身份及多帧验证。21 帧为不同静态场景，不可当作连续帧。
5. 这是一次离线隔离回放，不涉及训练、调 NMS、修改生产代码或正式传感器配置；不能据此断言动态场景性能、最终定位可靠率或比赛效果。
