# 多帧 LiDAR 实际流程对照（2026-11-12）

## 环境与范围

在服务器隔离端口运行 CARLA 0.9.16 Town03_Opt、真实 RGB/LiDAR/Radar、YOLOv8n ONNX 检测器及 Qwen/Qwen3.5-2B planner_v2；与既有 18006 Qwen 服务隔离。原 `target_live/scenario_layoutfix.json` 复制为两个实验场景，前车初始 40 或 60 米，另有远车和相邻车，目标持续运动；2 秒提交跟车指令。两组对照分别关闭和开启 `--experimental-temporal-lidar-frames 4`，同样默认 LiDAR 密度、检测阈值和安全规则。安全层和未验证几何门禁未放开。目标初始距离不是每帧实际距离。

每组 300 帧；单帧和多帧为不同运行，初始化和轨迹略有差异，不能视为对完全相同记录重放。没有将场景真值当作检测器输入或 Qwen 视觉证据；本次并未逐帧用真值核实多帧输出的目标身份和距离。

| 场景 | 识别到 car 的帧 | 其中多帧位置输出次数 | 指令时车辆候选 | Qwen / 结果 | 碰撞帧 |
|---|---:|---:|---|---|---:|
| 40 米 单帧 | 27/300 | 未开启；0 次单帧投影 | 无 | 不确定，拒绝跟车 | 0 |
| 40 米 多帧 | 38/300 | 10 次，均为未验证 | 无 | 不确定，拒绝跟车 | 0 |
| 60 米 单帧 | 0/300 | 未开启 | 无 | 不确定，拒绝跟车 | 0 |
| 60 米 多帧 | 0/300 | 0 | 无 | 不确定，拒绝跟车 | 0 |

40 米真实检测置信度范围：单帧 0.366–0.573，多帧 0.354–0.579；多帧的 10 次输出全部发生在指令提交之后，距离约 50.77–53.88 米（自车坐标原点至 LiDAR 表面），不能确认实际对应预定前车。Qwen 均记录 `abstained=true`、终态 `QWEN_LOW_CONFIDENCE`；指令后车辆停止。启动至指令提交前车辆有正常初始行驶，不能描述为全程停车。

传感器就绪到控制 `sensor_to_control_ms`，40 米单帧中位数 77.1、p95 112.6、最大 174.7；40 米多帧中位数 79.5、p95 132.9、最大 239.2。来自不同运行，不能将差异直接全部归因于多帧；该统计不是 Qwen 端到端语音延时。场景中存在超过 150 ms 的帧，未证明满足 150 ms 时限。

逐帧日志和场景：`artifacts/runtime/temporal_integration_20261112/40_single/`、`40_temporal/`、`60_single/`、`60_temporal/` 及同目录 `scenario_40m.json`、`scenario_60m.json`。结果页面的“真实流程对照”与理想真值框的早期关联实验分开展示。

## 结论与边界

真实流程中 40 米多帧获得一些未验证位置，但指令时无车辆候选，两种模式均未成功跟车；60 米无车辆检测。原因可能涉及图像中目标尺寸、检测置信度、视角、遮挡、传感器几何等，现有对照不能单独证明某一种原因。需要在不降低安全要求的前提下，针对实际检测器做远距评估、对齐并核验目标几何，开展更多场景和时延测试。该实验不证明实车能力或安全性。
