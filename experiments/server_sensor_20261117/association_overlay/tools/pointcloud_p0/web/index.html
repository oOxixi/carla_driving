定位误差诊断：先找原因

基于服务器保留的 55 次原始测试；定位算法没有改动。报告将可确定的现象和不能确定的原因分开。

1. 车辆位置差在哪里？

这里比较的是激光点簇的可见表面中心与 CARLA 车辆包围盒中心，不是已实现的车辆中心估计。121 个成功定位样本；另外 49 个不参与误差统计。

沿目标所在道路的前进方向拆分；纵向负数表示点簇在真值中心后方，横向正数表示道路左侧。道路坐标取目标真值处 Waypoint 切线，是本次直线路段的局部近似，并非弯道完整曲线坐标。

指标有符号中位数误差绝对值中位数误差绝对值 P95含义

P95 的意思：在这些成功样本中，约 95% 的误差不超过该值。最近表面距离是水平距离，真值为车辆包围盒的最近水平表面，不是车辆外形网格的精确表面。

2. 49 个失败样本：算法停在哪里

下表的状态互斥，总数为 49。5 个没有匹配检测框，不能判断框内点数；其余 44 个有检测框但没有输出定位。状态是算法记录的拒绝原因，不等于已经证明的物理根因。

进一步核查标签是可以同时出现的现象，不能相加当作 49 个的分类。语义点归属采用 0.08 米近邻核对；环境点存在不代表它一定导致失败。

“Radar 框内无独占点”不等于 Radar 损坏：当前算法允许没有 Radar 支持时仍定位；失败框没有保存逐点的雷达真值归属，不能直接断言 Radar 是失败原因。

3. 传感器标定和同步检查

55 份原记录的 RGB、LiDAR、语义 LiDAR 和 Radar 帧号均一致。原定位代码在运行时检查 RGB、LiDAR、Radar 时间差不大于 1 毫秒，但没有保存原始时间戳，因此不能从原记录重新算出具体时间差。

相机设定 800×450，水平视场角 100°，计算焦距约 335.64 像素，主点 (400,225)。相对于自车原点：相机向前 1.5 米、向上 2.2 米并俯视 8°；LiDAR 向上 2.35 米；Radar 向前 1.5 米、向上 1 米。55 份记录的相对安装位姿一致。

CARLA 原始坐标是前、右、上；报告把横向改为左正。真值采用车辆包围盒中心，传感器位置以自车原点为参考。旧记录未保存每辆车 Actor 原点位置，无法量化 Actor 原点与包围盒中心的差。

4. 当前结论和限制

纵向表面偏差是 2.28 米差距的主要组成；当前数据还不足以证明这完全由车辆后表面造成。定位失败集中在点数与聚类条件，但环境混入、遮挡、检测框重叠可能同时发生，无法仅靠一项计数证明因果。

此次只覆盖 Town05 一段直路、单一车型和静止车辆。没有对算法提出新的通过阈值，也没有开始多帧融合或部署到控制系统。
