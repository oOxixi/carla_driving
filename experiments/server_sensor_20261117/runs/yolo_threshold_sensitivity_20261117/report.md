双车覆盖定义：在重建场景的实例分割图上，一个检测框分别覆盖两个指定目标可见像素的至少 50%；这是候选混合风险，不等同于确认错误合并。重建的分割图不是原帧实例标注。

低分框正确三维点支持：匹配到目标的检测组按原始方案 C 得到 LOCATED_UNVALIDATED，且至少 3 个最终选中 LiDAR 点通过同步语义 LiDAR 的 0.08 m 最近邻核验全部归属该目标；未知、背景或其他车点均不算纯净支持。该指标不是车辆中心定位成功，也不是控制安全验证。

0.15 阈值的 1 个未匹配框在 holdout_250_30，与同一目标上的另一类别框同时存在，重建实例像素和 IoU 显示疑似跨类别重复；不能计为背景误检。未完成全部场景、背景及检测框的人工标注，不能据此计算真实误检总数。低分候选的图像复核材料为 review.html。

雷达数值只是同步回波与检测框、离线真值包围盒的近似空间核对，不能视为经验证的雷达目标绑定或实时控制依据。原始算法未加入新雷达证据或多帧融合。

同一帧的低分框可能影响唯一点归属，例如 holdout_250_30 在 0.20 时目标 T 的车框去地面后有 13 点，0.15 出现 car/truck 重叠后两组均为 0 点。此样本表明低分框需要隔离，不应直接并入正式链路。

明细见 detections.csv / detections.json；逐帧统计见 frames.json；元数据与参数见 metadata.json。

## 重要更正：0.20 混合回放对高分框的中间点归属有影响

此前 strong_group_changes 仅比较组成员、最终选中点、状态和原因，不能证明筛选过程的候选点不变。重新逐项比较发现，holdout_extra_250_25 的高分框候选点 14→13、去地面点 14→13；holdout_extra_250_39 的高分框候选点 9→7、去地面点 7→5。两者最终选中点与状态在本批样本中未变。详见 high_point_interference_020.json，检测脚本为 check_high_interference.py。不要将 strong_group_changes 为零理解为所有中间点归属无变化。
