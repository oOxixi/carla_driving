# 低置信度辅助目标的三维身份区分：两个样本验收

## 边界和方法

分支 experiment/3d-target-disambiguator-20261117 从 before-VLM-sense 创建。0.35 正式目标使用保存的正式检测与原方案 C；先冻结并保留正式点及正式框覆盖点，辅助候选在剩余点中保持唯一归属。0.52m、0.5098～0.60m 仅为这两例的离线测试。无多帧点云累积、无正式车辆控制。

Target3DDisambiguator 的输入只有同帧同传感器坐标、帧内点 ID、检测框、候选簇和时间戳。它先检查重复分配、帧／传感器／时间一致性，再报告三维点距和 LiDAR 径向深度分布。单帧缺连续观测、缺经独立标定的阈值时一律 UNKNOWN；即便未来传入研究阈值和连续观测，结果也标注 unvalidated 且无控制权限。Actor 真值和语义 LiDAR 在聚类及身份结果冻结后才用于离线核验。

## extra_250_25：正式目标与辅助候选

- 正式已选 11 点；辅助剩余 16 点，0.52m 形成 11 点候选簇。原始点 ID 交集 0。
- 归属明细：正式选中 11，辅助簇 11，辅助未选 5，正式保护但未选 1，过滤或歧义未分配 3。
- 正式簇 LiDAR 径向范围 15.185～15.391m；辅助簇 22.247～23.168m；区间间隔 6.857m，两簇最近三维点距 7.127m。
- 两簇呈现明显的单帧空间分离，与人工判断不同车辆一致；但缺少连续帧与独立标定准则，且不能仅凭分离排除簇内多物体混合。结论不是已经独立确认两个物理目标。
