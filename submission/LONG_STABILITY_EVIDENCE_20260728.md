# 30 分钟 CARLA + Qwen 长稳证据（2026-07-28）

## 结论

在服务器 `tiaozhansai` 的 GPU 0 上，同时运行 CARLA 0.9.16
`Town03_Opt`、低资源 RGB+LiDAR 和本地 `Qwen2.5-VL-7B-Instruct`，
完成 30 分钟墙钟稳定性测试，最终报告 `success=true`。

本测试验证传感器连续流、周期 Qwen 推理、GPU 资源和结束后的传感器重建；
它不是车辆持续沿路线驾驶 30 分钟的道路闭环测试。

## 结果

| 指标 | 结果 |
|---|---:|
| 要求持续时间 | 1800.000 s |
| 实际观察时间 | 1807.829 s |
| RGB/LiDAR 对齐帧 | 57,323 |
| 平均对齐帧率 | 31.708 FPS |
| 对齐帧丢失 | 0 |
| 非法传感器回调 | RGB 0 / LiDAR 0 |
| GPU 样本 | 354 |
| GPU 采样错误 | 0 |
| 平均显存 | 20,016.870 MiB |
| 峰值显存 | 20,018.000 MiB |
| 平均 GPU 利用率 | 34.133% |
| 峰值 GPU 利用率 | 56.000% |

传感器 callback 总数均为 57,326；其中 3 帧属于稳定窗口前的启动帧，
正式对齐窗口为 57,323 帧。

## 周期 Qwen

测试开始时立即推理一次，之后约每 5 分钟推理一次，共 6 次：

- READY：6/6
- 目标关联正确：6/6
- 10 秒预算超时：0
- 推理错误：0
- mean：2221.546 ms
- P95：3361.411 ms
- P99：3700.523 ms
- max：3785.301 ms

Qwen 在独立线程中作为事件触发的高层决策运行；RGB/LiDAR 连续帧在这些推理窗口
中没有丢失，说明当前异步方式没有阻塞本次传感器循环。

## 恢复

长稳结束后销毁自车和传感器，再重新创建 RGB+LiDAR 进行 20 帧恢复探针：

- 对齐帧：20/20
- 非法回调：0
- 结果：成功

这证明本次正常结束后的资源释放和传感器重建可用。尚未进行“强制杀死 CARLA
进程后自动拉起”的破坏性恢复测试。

- Qwen 使用固定的真实夜间 CARLA 图像和结构化目标上下文；
- 本结果只代表当前 RTX 3090、CARLA Opt 地图和低资源传感器配置；
- 尚未验证 CARLA 进程崩溃后的无人值守自动重启。
