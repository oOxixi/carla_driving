# 0.35 + 0.20 双通道隔离回放

21 帧、35 目标；原始正式框 10 个，辅助候选 9 个（按既有 IoU 规则自动匹配）。21 帧正式检测及方案 C 的组、状态、点状态、归属、原因在回放前后均一致。

正式通道先运行原方案 C（包括原方案雷达输入）；保留所有投影落在正式框内的点及所有正式 ASSIGNED 点。辅助通道只处理余下点，沿用方案 C 聚类，传入空雷达；点真值仅用于离线核验。辅助通道会在保留点上重新拟合地面，不能与基线的地面结果视为完全相同。

重叠检测：辅助框与正式框只要有正面积重叠即提示，跨类别重叠只是疑似重复，不认定为同一辆车。辅助框之间存在正面积重叠时也保守标记 AMBIGUOUS；未解决身份的其余候选为 VISUAL_ONLY。无输出进入控制。
