# Student 运行部署与依赖说明

本目录包含当前 Student 源码、常驻 JSONL 与 HTTP 入口、历史数据/RGB、便携启动器和基于官方 X86 镜像的 Docker 构建与导出脚本。启动器从包内已训练模型清单选择产物，不再默认加载随机初始化 ONNX。

X86 运行使用 Torch（预处理和 Adapter）、NumPy、ONNX Runtime、Pillow、jsonschema 与 PyYAML。既有官方镜像测量环境为 Python 3.10.12、Torch 2.8.0+cpu、ONNX Runtime 1.19.0；转换使用 horizon_tc_ui 3.5.16 与 HBDK 4.11.11。训练和 A1 分析环境单独以原件为准。

OpenExplorer 输入配置、冻结校准张量已放入 04_量化与编译输入/OpenExplorer输入；已有 BC/HBM、编译日志、节点落点与建议报告位于 05_B3性能与评测/03_BPU工具原报告。工具链产物对应目标 nash-p。

当前新增脚本负责包内 X86 启动与构建；未生成新的性能数字。指定芯片 SDK 调用、CPU/BPU 桥接与配置已补齐在 chip_runtime。已有 CPU 利用率原始数据已汇总在 05_B3性能与评测/异构利用率口径，BPU 分析与真实计数器分别标注。SDK 编译和实板运行仍需对应环境，不再列为待成员写代码。当前机器未发现 Docker 可执行程序，镜像实体需在可用 Docker 的官方环境机器按 build_and_export 脚本生成。按团队最新统一方案，实板运行和功耗为具备条件时的补充，不要求另购板卡。

官方环境包装脚本已改为 REPO_HOST、OE_HOST、WORK_HOST、DATA_HOST 参数配置，不再依赖原成员的 /mnt/d/nana 路径。B3 原始日志中的路径保留为历史溯源；日志路径不是包内启动配置。

实际 Docker 依赖约束、导出目标和版本检测以 docker/README.md 为准；正式运行镜像保留 B3 的 Pillow 9.3.0，不使用训练依赖覆盖实测运行库。
