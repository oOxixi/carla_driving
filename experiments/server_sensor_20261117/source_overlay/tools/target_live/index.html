新对比：使用 5880 服务器已有的视觉模型

使用同一批去掉画面顶部编号的 4 张 CARLA 输入画面；每张图各问左车和右车。模型收到相同图片、提示词和颜色输出选项，温度均为 0。5880 上的模型是 Q4 量化版，使用 Ollama 的 JSON 约束输出；VL 8B 产生思考内容，允许更长输出；第 7、8 次因截断用更长上下文和输出上限重试，与 2B 的推理设置不同。不同服务的图像预处理也可能不同。

正在读取结果…

绿色或橙色是目标框的颜色。正确答案来自 CARLA 车辆真值投影；输出来自各模型的真实推理。本页结果用于离线比较，不执行车辆控制。

当前共 4 个场景、8 个问题，样本量较小；每个问题独立调用一次。耗时为单次请求墙钟时间，受共享机器负载和模型预热影响，只供参考。

新对照：画面去掉 T1、T2 后，颜色选择会变化吗？

继续使用同一批 4 张真实 CARLA 画面和左右指令，擦掉画面顶部的 T1、T2，保留绿色框和橙色框；每张图仍分别提问左车和右车，模型直接输出颜色或“不确定”。

正在读取模型结果…

每组左图是上次带编号的输入，右图是这次去掉编号后的实际输入。除顶部擦除区域外，两图解码后的像素完全一致；新图使用无损 PNG。提示词中关于“顶部有编号”的一句也改成了“框是绿色和橙色”，候选的 T1、T2 身份仍存在于文字选项中。

正确颜色由 CARLA 车辆位置投影确定；框是仿真真值投影，并非检测器结果。本次是 4 个场景、8 次离线提问，各问一次；输出来自真实模型推理，不控制车辆，样本量不足以说明整体准确率或单独证明变化原因。

新对照：让模型直接输出框的颜色

复用下方左右测试的同一批 4 张真实 CARLA 画面和 8 条指令。上次让模型输出 A、B 或 Z；这次改为直接输出“绿色”“橙色”或“不确定”，并要求它按目标框的颜色回答。

正在读取模型结果…

绿色框是 T1，橙色框是 T2；说的是标注框颜色，不是车辆车漆颜色。正确答案来自 CARLA 车辆位置投影；两次使用同一张图片的原始文件。颜色名称可能需要多个词元，因此最大输出长度从 1 调整为 8；提示中的选项文字也随之改变。

每张图分别提问左车和右车。颜色实验通过同一 Qwen 模型的推理接口直接调用，输出为模型真实生成的颜色，并不是程序将旧字母答案改写成颜色。每组仅 4 个场景，不能据此推断整体准确率；实验不控制车辆。

新测试：模型能分清画面里的左车和右车吗？

4 个新生成的真实 CARLA 双车场景，每张图分别问左边和右边，共 8 次。相同画面内只改变指令；T1、T2 在左右两侧轮换。绿色框对应 T1，橙色框对应 T2。

正在读取实验结果…

正确答案由 CARLA 中车辆的实际位置投影到相机画面得到，按两车在画面中的左右位置判定；同帧语义分割检查两辆车确实可见。候选框使用仿真真值投影，并非检测器结果。模型只收到图像、编号及统一的未知位置候选信息，正确答案没有传给模型。

每张画面进行两次独立模型调用，属于同一场景的配对提问；共 4 个场景，不能当作广泛道路条件下的准确率。离线测试不控制车辆，也不衡量目标检测或车道识别性能。
