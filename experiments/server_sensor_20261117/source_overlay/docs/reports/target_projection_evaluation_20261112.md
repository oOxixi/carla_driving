# 相机与 LiDAR 目标关联：2026-11-12 阶段记录

## 修改范围

- `integration/camera_lidar_association.py`：验证同帧、可用时间戳、相机参数和刚体变换；使用连续点间隙聚类替代固定 2 米深度分箱。多个点簇仅在最近簇至少 8 点且不少于每个其他簇的 4 倍时选择，否则保持未知。这些数字是未经标定的保守启发式，不是安全保证。
- `integration/carla_perception.py`：投影异常时，不把前方通道距离赋给视觉目标；保留独立前方障碍物安全距离。
- `integration/canonical_bridge.py` 和 `interfaces/perception_state.schema.json`：增加位置质量、车道质量、距离参考的证据状态；视觉目标只有真正投影成功才标注 LiDAR 来源。位置和车道标为未验证，不捏造概率。
- 补充关联、坐标变换、输入校验和来源状态测试；调整旧测试使其区分前方安全距离与单个视觉目标的距离。

投影距离是自车坐标原点到观测点云表面中位数位置的水平距离，不是车辆中心距或车头净距。内部兼容接口尚以 50 米作为未知距离占位；必须结合 `position_quality` / `geometry_source`，不能把占位值当作测量。Qwen 请求对该类目标传 `null`。

- 第一轮综合回归：`python -m pytest -q integration/tests runtime/tests`，1005 passed、2 skipped；随后新增旋转变换测试，关联相关四组专项测试 103 passed。上述测试使用服务器 `carla-driving-challenge/.venv`。
- 临时 CARLA 0.9.16，Town10HD_Opt，独立端口 22100 和 GPU 5，单车静止场景，默认 800x450 RGB、32 线 LiDAR、224000 点/秒。每个距离计 8 帧；相机检测框来自仿真真值，仅用于隔离评估关联，不表示真实检测器性能。真值没有进入关联算法或车辆决策。
