# 千问复杂指令全链路改进总结（2026-08-06）

## 已完成

- 新增可解释的三路复杂度路由：`FAST_LOCAL`、`QWEN_PLAN`、`CONFIRM_SAFE`，覆盖多动作、条件时序、视觉指代、复杂机动、安全冲突和歧义目标。
- 新增严格 `ManeuverPlan V2` Schema、Planner V2 提示词、解析器、场景可行性校验和计划编译器；递归拒绝 `throttle/brake/steer` 等低层字段。

- 修正两个安全/场景问题：`EMERGENCY_BRAKE` 纳入 C 层 fail-closed；场景车辆按道路表面高度生成，避免碰撞盒嵌入路面。
- 新增并登记 9 个 P0 场景：QWR 4 个、QWF 2 个、QWX 3 个，含超时和非法低层字段故障注入。
- 补齐路由、Schema、校验、编译、FSM、异步、故障、场景契约和监控测试。
