# 裁剪复检与跟车实验（2026-11-12）

## 范围与更改

服务器独立端口 CARLA 0.9.16 Town03_Opt，实际 RGB/LiDAR/Radar、YOLOv8n、4 帧实验 LiDAR、Qwen3.5-2B planner_v2、正常 A/B/C/D 安全链；每场景 150 帧实际运行，另有 29 帧预热记录。指令为“跟随最近的同车道正前方车辆，不要跟相邻车道或远处车辆”。目标初始 40/60 米，运动后指令时实际距离不同。另将 60 米场景前方增加一辆同车道运动车构造重叠遮挡。首次遮挡场景因远车超出路线配置，未执行，后改至 78 米重跑。

新增 `integration/experimental_crop_detector.py`，由 `--experimental-crop-detector` 显式开启：整图以 0.05 提取低分候选，0.35 筛选正式框；固定前方 ROI、至多两个未被确认的低分车候选 ROI 裁剪自原图，以 0.35 复检，结果坐标复原并按类别 NMS。固定 ROI 命中低分候选后跳过重复复检。低分候选不直接进入正式输出。新增默认关闭的 `--experimental-onnx-threads` 可选 CPU 线程数；三次下列闭环均未启用该选项。未改变语义校验、传感器几何可信门槛、纵向安全规则或线上服务配置。无真值输入控制：`tools/target_demo/evaluate_crop_follow.py` 只在旁路记录 actor 真值、检测和指令时刻 RGB，事后评估。

## 指令时与逐帧结果

逐帧统计使用真值三维包围盒投影与检测框 IoU，取最匹配对象并要求 IoU≥0.3；这是检测框相似性统计，不保证模型知道目标身份，也不验证隐藏对象是否真的被识别。各次运行非同帧重放。试验结论：

| 场景 | 指令时相机到指定前车的前向距离（近似） | 前车/近遮挡车匹配帧 | 指令结果 | 碰撞帧 |
|---|---:|---:|---|---:|
| 40 初始 | 48.24m | 前车 143/150 | Qwen 选 C-0002；框与旁车真值重合 IoU 0.789，与前车 0.016；语义校验拒绝 | 0 |
| 60 初始 | 66.12m | 前车 55/150 | Qwen 选 C-0005，框与前车投影重合 IoU 0.650；语义校验拒绝 | 0 |
| 遮挡 | 近车 49.35m，后车 65.19m | 近车 33/150 | C-0012 同时与近车和后车投影框重叠；语义校验拒绝 | 0 |

40 米有 150/150 帧检出至少一个 car，60 米 91/150，遮挡 77/150；分别有 267/274、144/155、100/110 个车辆检测至少缺距离或车道关系。重叠遮挡场景中 57 个检测与近车和后车投影 IoU 均≥0.3，二维框无法确认归属；验收日志将 C-0012 归给后车，但指令帧该框与近车投影 IoU 0.863、后车 0.474。现有验收代码基于近似水平角和贪心映射且缺距离时无法可靠区分重叠目标，归属应视为未知，不应据此宣称成功跟车。

三个场景模型请求已实际发送，日志均为 `SEMANTIC_LOW_TARGET_CONFIDENCE`。`runtime/scene_evidence.py` 中候选分数低于 0.8 标记低置信；同车道、最近等条件还需可信传感器几何和车道关系。40 米指令帧两候选 0.764、0.748 且距离/车道均未知。视觉候选的出现不代表得到可靠距离，安全层可能以 visual hazard without range 执行制动。三次均未完成跟车，不应解除安全门槛来制造成功。
