# 数据集构成来源与划分说明

训练及历史评测数据来自 B1 发布的 CARLA 场景采集版。每条案例含 ModelRequest、RGB 引用、Teacher 结构化计划、场景与运行 metadata、目标绑定和质量信息。Teacher 固定模型 revision 与各历史采集代码身份分别保留，不覆盖历史溯源记录。

本包已直接归入本地可取得的九个数据发布目录、历史治理文件和既有 RGB 快照，路径位于 02_源码与部署/source/challenge/dataset 与 challenge/hil/frozen。训练数据的治理与去重边界由原始 manifest 描述；实际训练采用 A3 的严格正样本视图。

| 数据范围 | 数量 | 用途 |
| --- | --- | --- |
| B1 治理 Train / Dev | 6037 / 1158 | 历史训练与开发数据 |
| A3 鲁棒 V3 训练视图 | 5856 / 1108 | 本次训练与开发 Validation |
| Calibration v1 | 300 例 | 量化校准，另含 1200 个工具链输入张量 |
| 历史 Independent Validation v1 | 240 例 | 既有诊断记录，保留历史用途边界 |
| B3 六队列用例比较 | 850 例 | 同步比较 Teacher 计划与 Student 输出 |
| CARLA 自建验收矩阵 | 83 场 | 闭环完成与安全记录 |
| Teacher / Student 共有场景 | 47 场 | 同场景判据的宏平均比较 |
| 历史语音模块 ASR 实跑 | 250 条 edge-tts 合成 MP3 | 音频、转写真值与逐样本识别结果均已收录；历史 GPU 条件 |
| 新 Seen / Variant / Unseen 方案 | 80 / 80 / 80 | 冻结方案；尚待真实采集 |

队列名称、规模和原始结果见技术报告和 B3 原件。语音模块的 250 条合成 MP3、转写真值、Clean / 10 dB SNR 逐样本 ASR 输出与历史日志位于 历史ASR实跑证据；当前源码 voice_group/test_samples 亦保留对应输入。语音样本的来源和环境按历史附录说明，当前提交模型的同基准应用指标前后对照仍待 B2 汇总。
