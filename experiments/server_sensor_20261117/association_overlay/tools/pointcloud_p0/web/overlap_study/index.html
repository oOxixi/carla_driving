先看发现

两个框几乎完全重合：一个写“汽车”，另一个写“卡车”；事后真值显示它们对应的是同一辆车。不能把这两个框当成两辆已经确认存在的车。

2. 三种方案对比

“分到框”只是第一步，不能把其中的环境点当作车辆点；算法还要去地面、聚类和拒绝不确定点。距离是自车原点到最近选中点的水平距离，并非车辆中心距离。

A：原方法

凡是同时落在两个框里的点全部排除，避免误分配，但这次同时丢掉了大量车辆点。

B：归一化框中心距离

按每个点到两个框中心的归一化距离选框，53 个点都分配了，但同一辆车被拆到两个重复框。它本身不能证明车辆归属正确。

C：框中心 + 三维点簇一致性

先单独检查两个框能否形成同一个稳定点簇：本例两个框重叠度约 0.970，独立得到的车辆点簇完全相同，前后位置差为 0 米，因此暂时把这两个检测 ID 作为同一组。其他重叠框需要同时满足二维中心和三维点簇证据，否则标记 AMBIGUOUS（无法确认）。

这一合组只是试验假设，不代表相似框一定是同一辆车。阈值尚未经过独立验证，且原始记录没有历史目标位置，不能进行基于历史轨迹的判断。

当前结论

C 在这一个夜间样本中从“无法定位”恢复为 18 个目标车点的点簇，但 35 个目标车重叠点中还有 17 个没有进入最终点簇；18 个环境点中有 11 个被地面或高度规则过滤，另 7 个与未选中的车点一起保持无法确认。因此，逐点去向记录已完成，但还不能宣布单帧归属问题已经解决。
