# 七项验收指标：候选级聚类离线实验

## 统计口径

主验收集按任务指定的 5 个目标分别统计：extra_250_25、250_30/C-0002、extra_250_21、extra_250_39、extra_250_47。基线全部使用 R0；探索对照仅对 extra_250_25 使用 0.52m，其他 4 个仍使用 R0。这是针对单个样本调试的混合配置，不是已经确定的通用距离自适应策略。

语义 LiDAR 采用 0.08m 最近邻，仅在选簇之后近似核验。候选目标身份来自自动 IoU 匹配，且语义核验不等于完全真值。Recall 分母是正式框保护、方案 C 归属和去地面后剩下的近似目标点；不是传感器原始全部目标点或整车点。没有选中点时 Precision 未定义；近似目标点分母为零时 Recall 未定义。

## 范围核验

正式链路离线核验脚本 verify_formal_chain.py 在与实验相同的 7 帧执行辅助处理和实际半径扫描前后，比对保存的 0.35 模型检测、跟踪 ID、类别、置信度、框，并比较方案 C 全部返回字段及数组哈希；还验证正式保留点没有交给辅助通道。审计见 formal_chain_audit.json。没有集成辅助结果到实际运行时，因此未测试车道、FOLLOW、控制或跨帧。

距离和纯度只说明本次观测，尚不能验收通用定位质量、时间稳定性或比赛运行性能。
