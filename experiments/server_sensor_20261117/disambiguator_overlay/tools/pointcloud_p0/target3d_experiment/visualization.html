这次实验，看懂两件事

我们想知道：相机里的两个框虽然重叠，激光雷达（LiDAR）的点云能否帮助判断它们是不是两辆不同的车。

第一个样本：两组点前后分开，但只有一帧，系统还不能自动确认身份。
第二个样本：没有正式检测框，辅助点也没有聚成簇。

本页展示离线实验；没有把低分候选接入驾驶控制。下面的圆点是激光回波，不是车辆中心，也不表示车辆完整形状。

样本一：两个框重叠，点云是否分开？

结论：点云前后分开；系统状态仍为“不能确认”。您此前人工复核判断画面中是不同车辆，但算法还缺少连续帧和经过验证的判断标准。

蓝点到激光雷达的距离加载中
黄点到激光雷达的距离加载中
两组距离区间间隔加载中

两组点没有使用同一个原始点。黄点形成的只是待核验的点簇，不能当作已确认的车辆中心或跟车目标。

为什么还不确认？当前只有这一帧，也没有经过独立场景验证的身份判断阈值；几何分开不能单独证明两个点簇各自都属于一辆完整汽车。

样本二：为什么没有恢复点簇？

结论：这一帧没有正式框；辅助候选的 13 个点在测试范围内没有聚成簇。

测试的最大连接半径0.60 米
最近两个候选点间距约 0.62 米
形成的点簇0 个

因为最近两个点都超过本轮最大连接半径，没有点连起来。没有点簇时，无法计算该候选的定位误差或判断是否误合并。

这次结果能说明什么？

第一例说明：对于这一次画面，辅助目标的部分点可以组成候选簇，并且与正式目标点云分开。第二例说明：同一个半径范围无法恢复另一辆车。目前两例都还不是可信的自动定位结果。
