## 对当前项目的直接执行结论

1. **延迟口径要双记。** 答疑称“传感器接收完全部信号到模型输出轨迹”，评分表称“语音输入到车辆执行动作”。为规避口径差异，同时记录模型服务延迟和完整闭环端到端延迟。
2. **B 角色正式主线改为 Qwen3.5-2B BF16/vLLM。** A800 属于 Ampere，FP8 不是原生 W8A8 默认加速路径；80GB 显存没有必要为了装载模型先量化。固定模型 revision `15852e8c...`、vLLM 0.26.0、BF16、non-thinking、batch 1、2048 上下文。
3. **消除完整 JSON 自回归。** 模型只输出一个受约束的 `A/B/C/D/E` 代码；速度、目标 ID、置信度、确认状态和安全覆盖由确定性代码完成，最终仍经过严格 Schema。视觉输入固定为 256×256 场景/目标拼图，对应 64 个合并视觉 Token。
4. **Docker/README/Jupyter 是硬交付。** README 必须给出输入输出、预期结果和一键复现；Jupyter 用最短路径复现一条样例及指标，不写重复说明。
5. **环境差异必须显式记录。** 旧答疑给出评测参考环境 A800 80G/CUDA 13.2；本地 RTX 5070 8GB 结果只能作为开发自测，不能冒充官方复现成绩。
6. **数据集无官方强制规模。** 重点是统一时间戳/帧关联、语义清晰、格式一致、可追溯；评分阶段使用主办方不公开评测集。
7. **测试顺序固定。** A800 上预热 5 次、测量 10 次；P95 大于 300 ms 立即早停，不跑正确率集。P95 不大于 300 ms 后才跑现有冻结正确率集合，通过后再做一次 30 分钟稳定性测试。
