## 传感器密度诊断

临时从 32 线/224000 点每秒提升至 64 线/2240000 点每秒，仅为隔离实验，RGB 和安全门槛保持不变；三组是不同轮次，并非严格同帧对照。40/60/遮挡距离可用帧分别 25/30/27（各 150）；未验证的旁路融合有输出的帧分别 102/41/65。三组仍 FAILED，碰撞 0；40 米因低目标置信度被拒绝，60 米及遮挡模型不确定。传感器变更不代表赛题或硬件许可。

## 模型同帧回放

40 米和 60 米各取一个历史原始 RGB 指令帧，用同一检测器候选框分别生成全图和中心裁剪图；检测框与仿真角色投影仅事后用于判断。4 次原排序调用模型均选 B（邻车）；交换候选顺序后 4 次均选 B（变成投影更接近前车的候选；40 米图像存在重叠，身份仍不确定）。另用两种中文提示直接选择 T1/T2，交换顺序前后各 4 次共 8 次均选择 T1；物理目标随排序改变。全部为离线调用、不连接车辆控制。样本仅两个场景各一帧，不能据此统计模型总体准确率，但足以说明单靠换序、裁剪或当前提示不能证明目标可靠。
