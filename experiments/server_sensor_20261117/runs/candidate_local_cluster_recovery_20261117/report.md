# 候选级局部聚类恢复：离线实验报告

## 研究范围和方法

复用 0.35 正式检测和 0.20～0.35 辅助候选；选用人工复核为真实新增车辆的 8 个目标假设，覆盖 7 帧，其中包含要求的 5 个验收样本，以及额外的 3～5 点样本。先独立运行并冻结正式方案 C，保护正式框内全部投影点及正式选中点；辅助候选在剩余点中保持单目标分组，保留重叠歧义。复用方案 C 去地面、唯一归属和几何上限，辅助通道不使用雷达。

针对 extra_250_25，依次扫描原自适应 R0 与 0.45、0.48、0.52、0.55 米；其余样本只评估原 R0，不做扩大半径试验或深度硬门控。基于每个候选内空间距离排名和 LiDAR 径向深度差排名等权计算相对观察评分，仅供网页排序观察；该评分未标定、不用于连边、删除、身份确认或阈值决策。

聚类图和候选选择全部固定之后，才用同帧语义 LiDAR 在 0.08 米内近邻近似核验点归属，并用 Actor 包围盒核验表面距离；角色仍来自自动 IoU 匹配，不等同于人工确认的物理身份。目标真值不进入聚类、点分配或正式链路。

## 验收和限制

1. 只在 extra_250_25 的 4 个非基线几何簇中核验了点纯度；均为 100% 近似目标点，条件 Recall 在 18.75%～68.75%。没有观察到近似其他车辆点，但干净样本不能检验混合场景的错误合并。
2. 已形成 4 个半径条件下的单帧几何候选，覆盖的是同一个目标、同一帧，不是 4 辆成功定位车辆。不存在经验证的车辆中心、稳定表面距离或实时 FOLLOW 目标。
3. 正式通道在 8 个目标假设对应的 7 帧上对比重跑，组内容、状态、点状态、点归属、原因和地面结果一致；实验输入候选点均不包含正式保留点。
4. 采用几何点重新独立重算全部 12 个方案的连通分量与选中点，结果一致。无真值参与的算法图和事后语义审计保持分离。
5. 所有半径均为离线诊断，不是最终参数。没有新的数据采集、传感器改动、YOLO 重训、正式部署或多帧融合。
